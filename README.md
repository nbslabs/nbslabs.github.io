## What is nbslabs?

nbslabs is a Bangladeshi developer community and open-source initiative dedicated to building the next generation of software engineers. Founded by working engineers who experienced the gap between university curricula and production-grade software development — nbslabs exists to close that gap through hands-on coding, mentorship, open-source collaboration, and AI-augmented learning.

## Programs

| Program | Description |
|---------|-------------|
| **AI-Powered Coding Workshops** | Hands-on sessions with GitHub Copilot, Claude Code, prompt engineering, and agentic workflows |
| **Community Workshops** | Free, live workshops every 2–3 weeks — beginner to advanced, all recorded publicly |
| **Kids Coding Club** | Weekend sessions for young learners (Scratch, Python, JavaScript) |
| **Open-Source Contributions** | Structured contribution pathways into nbslabs tools and third-party ecosystems |
| **Premium Mentorship** | Personalized 1:1 guidance from industry practitioners matched to your career trajectory |
| **Vibe Coding Sessions** | Collaborative flow-state coding sprints — hackathon energy, no burnout |

## Open-Source Projects

### dotai (`@nbslabs/dotai`)

The flagship project. dotai unifies AI coding assistant configurations (Claude Code, Gemini CLI, Antigravity, GitHub Copilot) under a single `.ai/` directory, synced via symlinks — write once, all tools stay in sync.

```bash
npm install -g @nbslabs/dotai
```

**Status:** v3.0.0 released · [npm](https://www.npmjs.com/package/@nbslabs/dotai) · [GitHub](https://github.com/nbslabs/dotai-cli)

### In Development

- **WikiForge** — AI-native code documentation platform via MCP server
- **codeograph** — Code Knowledge Graph MCP server (SQLite + Tree-sitter)
- **tracely** — Sidebar navigator for AI chats. Jump to any prompt, rename messages, and manage long conversations in ChatGPT, Gemini, and Claude

The site follows the nbslabs brand guidelines:
